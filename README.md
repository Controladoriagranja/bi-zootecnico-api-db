# BI Zootécnico - Protótipo

Protótipo do novo dashboard web do Índice Zootécnico.

## Frontend

- HTML
- JavaScript
- Tailwind CSS
- Apache ECharts

## Backend

- Python
- FastAPI
- DuckDB
- Parquet

## Objetivo

Substituir inicialmente apenas o relatório
Indicadores Zootécnicos do Portal BI.

## Dados

Os dados reais não ficam armazenados
neste repositório.

O backend lê os arquivos Parquet
da rede interna da Granja Brasília.
